# 出装顺序优先级

## 通用顺序法则
```
第一大件 → 鞋子 → 第二大件 → 第三大件（穿透/功能） → 复活甲/春哥 → 神装
```

## 第一大件
- 通常在你回城 2-3 次后完成（约 12-15 分钟）
- 这是最强的 individual power spike
- 买完第一件立刻找人打架——你比对面多一个大件属性

## 第二件前的问题
- 对面已经在堆抗性了？→ 第二件出穿透
- 对面刺客秒你？→ 第二件出保命装（中亚/饮魔刀）
- 正常发育？→ 按核心装备继续出

## 什么时候出复活甲
- 第三个大件之后
- 或者你们马上要打大龙团
- **永远不要第二件出复活甲**——没伤害的复甲是纸

## 什么时候开始买药水
- 钢铁合剂：对方有猴子/劫/锐雯，打团前喝
- 巫术合剂：法师打团前必喝
- 愤怒合剂：AD 打团前必喝
- 一般 25 分钟后开始考虑
