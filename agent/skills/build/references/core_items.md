# 各位置核心装备

## 上单 (Top)
- 战士：渴血战斧 / 三相之力 → 死舞 / 血手 → 复活甲
- 坦克：日炎 / 冰拳 → 反甲 / 自然之力 → 石像鬼板甲
- 法师：永霜 / 卢登 → 中亚 → 法穿杖
- AD 刺客：星蚀 / 幽梦 → 赛瑞尔达的怨恨 → 复活甲

## 打野 (Jungle)
- 战士打野：渴血 / 星蚀 → 死舞 → 血手
- 坦克打野：辉耀美德 / 冰拳 → 反甲 → 自然之力
- AP 打野：暗夜收割者 / 腰带 → 中亚 → 法穿杖
- 攻速打野：破败 → 鬼索 → 智慧末刃 / 冰心

## 中单 (Mid)
- 法师：卢登 / 永霜 → 中亚 / 影焰 → 法穿杖 → 帽子
- AD 刺客：幽梦 / 星蚀 → 幕刃 / 赛瑞尔达 → 复活甲
- 攻速法师：纳什之牙 → 峡谷制造者 → 帽子

## ADC (Bot)
- 暴击流：收集者 / 海妖 → 无尽 → 多米尼克 → 饮血 / 复活甲
- 攻速流：鬼索 → 破败 → 智慧末刃 → 复活甲
- 穿甲流（女枪/维鲁斯）：幽梦 → 赛瑞尔达 → 幕刃
- **通用法则：先出攻击力装（收集者/海妖）> 攻速装 > 暴击装**

## 辅助 (Support)
- 法辅：帝国指令 / 月石 → 流水法杖 → 救赎
- 硬辅：钢铁烈阳之匣 / 薄暮法袍 → 骑士之誓 → 反甲
- 游走辅：皇冠 / 舒瑞亚的战歌 → 香炉 / 流水法杖
