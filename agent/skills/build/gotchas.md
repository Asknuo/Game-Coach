# Build 坑点清单

## 重伤装备
- **重伤不是看到对面有吸血就必须第一件出**：好多低分段玩家第一件裸执行死刑宣告
- 对面剑魔/吸血鬼/红凯隐 → 第一件重伤很合理
- 对面 ADC 出了个破败 → 第三件以后再出重伤就行
- 唯一例外：打野/辅助可以先出执行宣告/湮灭宝珠作为第二件

## 鞋子选择
- 水银鞋 vs 布甲鞋的选择取决于对面控制链长度，不是伤害类型
- 对面有莫甘娜+日女+塞拉斯 → 水银鞋。对面有劫+剑圣+德莱文 → 布甲鞋
- **法师不一定要出法穿鞋**：对面控制多时水银鞋 > 法穿鞋
- 辅助 800g 的鞋子比 1300g 的二级工资装更有用（游走速度 > 属性）

## 出装顺序
- 神话/大件出来之后立刻做鞋子，不要头铁硬憋第二件
- **装备比等级更重要**：2 件装备 vs 1 件装备 = 你比他强 60%
- 对面已经开始堆魔抗/护甲了 → 第二或第三件必出穿透装
- ADC 第一件收集者 = 对线强；第一件破败 = 坦克杀手；不知道出什么就收集者

## 辅助通用
- 辅助先出鞋子比先升二级工资装更重要（游走决策 > 经济）
- 对面有硬辅（泰坦/日女）→ 血手/钢铁烈阳之匣优先
- 对面有软辅（奶妈/风女）→ 二级工资装优先，不急着魔抗
- 工资装升级路线：冰霜女皇的指令（进攻）vs 星界据守（防守）

## 敌方装备
- **不能只看自己装备，必须看对面在出什么**：对面出反甲你还堆暴击 = 自己打自己
- 敌人买了秒表/金身 → 已经在防你，别硬开这个人
- 对面 ADC 出了破败 → 你这边一定有坦克在受苦，出荆棘之甲帮队友
- 多个敌人开始堆护甲/魔抗 → 第二或第三件必出穿透，别犹豫
- 对面中单出了杀人书/杀人戒 → 前期死 1-2 次没关系，但一旦超过 5 层必须针对
- 对面辅助 15 分钟就出了钢铁烈阳之匣 → 对面要打团了，跟团别带线
